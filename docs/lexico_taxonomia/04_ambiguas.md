# Términos ambiguos y decisiones pendientes

Estos términos son especialmente útiles para medir desacuerdos entre anotadores. No les asigno una clase fija porque su uso puede cambiar por destinatario, tono, contexto, dialecto o significado literal.

| Término                                                                            | Lecturas posibles                                                                                                                                                                                                            | Decisión que falta                                                                                                                                                                                        |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cerote/a`                                                                         | Insulto; trato coloquial entre conocidos; referencia literal vulgar. Este es lenguaje Vulgar u Ofensivo, se clasifica como ofensivo.                                                                                         | ¿Qué evidencia de dirección/hostilidad convierte el vocativo en label 1? ASALE registra el sentido despectivo regional, pero el corpus necesita usos locales. [ASALE](https://www.asale.org/damer/cerote) |
| `maje`                                                                             | Persona/compañero; “tonto”; descalificación. Por si solo es no tóxico, pero si se acompaña con lenguaje ofensivo es ofensivo y si se acompaña con discurso de odio también lo es.                                            | Marcar destinatario y tono. [ASALE](https://www.asale.org/damer/maje)                                                                                                                                     |
| `chero/a`, `cipote/a`                                                              | Amigo/persona; niño/muchacho; uso afectivo o insultante según frase. Lenguaje no ofensivo.                                                                                                                                   | Usarlos como controles dialectales; no inferir clase desde el lema. [chero](https://www.asale.org/damer/chero), [cipote](https://www.asale.org/damer/cipote)                                              |
| `guanaco/a`                                                                        | Relativo a El Salvador; persona tonta/simple en otro uso registrado. Lenguaje no ofensivo.                                                                                                                                   | Separar gentilicio de uso despectivo. [ASALE](https://www.asale.org/damer/guanaco)                                                                                                                        |
| `bolo/a`                                                                           | Borracho/a o aturdido/a; descripción, burla o insulto. Lenguaje no ofensivo.                                                                                                                                                 | ¿Es autorreferencia, descripción o ataque? [ASALE](https://www.asale.org/damer/bolo)                                                                                                                      |
| `chucho/a`                                                                         | Perro; apodo/insulto o frase figurada. Lenguaje no ofensivo.                                                                                                                                                                 | Resolver con contexto y sentido literal. [ASALE](https://temporalweb.asale.org/dhle/chucho)                                                                                                               |
| `púchica`, `puya`                                                                  | Interjección eufemística; otras acepciones léxicas. Lenguaje no ofensivo.                                                                                                                                                    | No tratarlas como grosería dirigida sin evidencia. [púchica](https://www.asale.org/damer/%C2%A1p%C3%BAchica%21), [¡puya!](https://www.asale.org/damer/%C2%A1puya%21)                                      |
| `mierda`, `verga`, `puta`, `puto`                                                  | Insulto; interjección; intensificador; referencia sexual; posible ataque sexista/homófobo. Lenguaje Ofensivo                                                                                                                 | Definir destinatario y criterio de solapamiento entre labels 1 y 2.                                                                                                                                       |
| `negro/a`, `indio/a`, `judío/a`, `musulmán/a`, `gitano/a`, `mujer`, `gay`, `trans` | Descriptor neutral; autodenominación; cita; estereotipo o insulto identitario. Lenguaje no ofensivo, pero acompañado con otras palabras ofensivas o de discurso de odio se vuelve a su taxonomía según orden de procedencia. | La mención del grupo no basta. ¿Hay generalización, degradación, exclusión o discriminación? [ONU](https://www.un.org/en/node/165070)                                                                     |
| `pobre`, `ignorante`                                                               | Condición/atributo descriptivo; menosprecio de clase o capacidad.                                                                                                                                                            | Definir el alcance de “clasismo” en label 2.                                                                                                                                                              |
| `arenero/a`, `terengo/a`, `foca`, `comunista`, `bukelista`                         | Identidad/afiliación política; apodo despectivo; crítica a una postura o partido.                                                                                                                                            | La fuente nueva los pone en una subclase política provisional. Decidir si esa subclase va en label 2 o label 1.                                                                                           |
| `marero/a`, `pandillero/a`                                                         | Descripción de afiliación; acusación; insulto; destinatario de amenaza o deseo de daño.                                                                                                                                      | No equiparar automáticamente afiliación delictiva con identidad protegida ni con una amenaza. Registrar por separado el contenido violento.                                                               |
| `matar`, `muerte`, `mueran`, `exterminar`                                          | Amenaza/intención; exhortación; deseo; noticia/cita; metáfora.                                                                                                                                                               | Anotar agente, destinatario, modalidad, negación y si se promueve daño físico.                                                                                                                            |
| `basura`, `perro/a`, `simio`, `salvaje`                                            | Sentido literal; insulto; deshumanización racial/identitaria.                                                                                                                                                                | Revisar objetivo y el grupo al que se aplica.                                                                                                                                                             |

## Reglas recomendadas para los casos difíciles

- Registrar **etiqueta primaria** y atributos como `target_group`, `directed_at_person`, `explicit_threat`, `quoted_or_reported`, `dialect_feature`.
- Si solo se permite una etiqueta, definir por escrito la precedencia entre amenaza (3), odio (2) y ofensa (1), y aplicarla consistentemente.
- Revisar juntos los casos que contienen insulto y grupo identitario; no convertir automáticamente una palabra ofensiva en discurso de odio.
- En el conjunto recién recolectado, validar manualmente antes de incorporar vocabulario extraído a reglas de entrenamiento.

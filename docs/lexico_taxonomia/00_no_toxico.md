# 0 — No tóxica

Lista de **usos y controles neutrales**. No es una lista blanca: cualquiera de estas formas puede aparecer dentro de una frase ofensiva, discriminatoria o violenta.

| Forma candidata | Descripción para revisión | Procedencia / nota |
|---|---|---|
| `maje` | Trato coloquial para una persona; también puede significar tonto o usarse para despreciar. | ASALE lo registra con sentido de persona tonta en varios países centroamericanos, incluido El Salvador; revisar el tono. [ASALE](https://www.asale.org/damer/maje) |
| `chero`, `chera` | Amigo, compañero cercano o persona, según el uso. | ASALE registra el uso salvadoreño de amigo/compañero y persona. [ASALE](https://www.asale.org/damer/chero) |
| `cipote`, `cipota` | Niño o muchacho; en El Salvador también puede aparecer con otros sentidos afectivos. | ASALE. [ASALE](https://www.asale.org/damer/cipote) |
| `pisto` | Dinero; también aparece en expresiones coloquiales. | ASALE registra “dinero” para El Salvador. [ASALE](https://www.asale.org/damer/pisto) |
| `guanaco`, `guanaca` | Gentilicio/adjetivo relativo a El Salvador; la misma entrada registra otro sentido peyorativo de persona tonta. | No inferir toxicidad por la palabra aislada. [ASALE](https://www.asale.org/damer/guanaco) |
| `bolo`, `bola` | Puede describir a una persona borracha o aturdida; puede ser descriptivo, burlón o insultante. | ASALE; llevar a revisión contextual si se dirige a alguien. [ASALE](https://www.asale.org/damer/bolo) |
| `chucho`, `chucha` | Puede referirse al perro; la forma tiene usos figurados y depende de la frase. | ASALE documenta un uso salvadoreño referido a un perro mestizo/callejero. [ASALE](https://temporalweb.asale.org/dhle/chucho) |
| `¡púchica!` | Interjección eufemística de sorpresa, enfado, contrariedad o miedo; no necesariamente insulta a alguien. | ASALE. [ASALE](https://www.asale.org/damer/%C2%A1p%C3%BAchica%21) |
| `¡puya!` | Interjección salvadoreña de admiración o sorpresa; distinguirla del sustantivo/otras acepciones de `puya`. | ASALE. [ASALE](https://www.asale.org/damer/%C2%A1puya%21) |
| `vos`, `sos`, `veá`, `vaya` | Formas coloquiales o dialectales que no son tóxicas por sí solas. | Candidatas para controles de dialecto; validar grafías en ambas fuentes. |
| `pupusa`, `familia`, `gracias`, `bendiciones`, `partido` | Referencias cotidianas frecuentes en el corpus; no indican toxicidad sin el resto del mensaje. | Vocabulario observado en ejemplos reales del corpus; no usar como lista blanca. |
| `hondureño`, `venezolano`, `salvadoreño`, `judío`, `mujer`, `musulmán` | Menciones descriptivas de nacionalidad, religión o identidad. | Una mención neutral no basta para asignar odio. La frase y su intención son necesarias. |

## Frases de control ilustrativas

Ejemplos construidos para revisar límites; **no son textos recolectados ni nuevas filas de entrenamiento**:

- «Mi chero me guardó el asiento».
- «El cipote fue por pupusas».
- «Me falta pisto para el bus».
- «¡Púchica, qué golazo!».
- «Mi vecino es hondureño».
